/home/jgon/.config/matplotlib is not a writable directory
Matplotlib created a temporary cache directory at /tmp/matplotlib-lsn8_l2z because there was an issue with the default path (/home/jgon/.config/matplotlib); it is highly recommended to set the MPLCONFIGDIR environment variable to a writable directory, in particular to speed up the import of Matplotlib and to better support multiprocessing.
