# Prospective offline analysis preparation

These tools audit completed study L without running scientific lives. They were prepared and independently reviewed before L outcomes were read. This separate bundle leaves the original 68-artifact public preparation and its provenance unchanged.

The analyzer binds the fixed s7 row29 source and original pilot, both 32-genome initial populations, every recorded generation of genetic inheritance, final checkpoints, and all 12 raw confirmation ledgers. Both fixed endpoints and every effect sign remain. The primary mixture averages three durations within each shared life seed before computing uncertainty across the 256 seed clusters.

It checks completion before reading outcomes. Completed export preserves the original public preparation under `prelaunch/`, independently reanalyzes the copied archive, and compares the summary and paired contrast bytes before publishing its final provenance.

The analysis adapts the reviewed D analyzer and reuses an exact frozen G genetic replay helper, both included under `sources/`. The fixed prospective initialization files and founder are copied as test fixtures. Tests use synthetic or mocked data and the existing preparation; no kernel simulation is performed. All 33 tests passed twice, including an independent reviewer run, and lint passed.

Run from the repository after L completes:

```sh
.venv/bin/python outputs/autonomous_s7_20261014/analyze.py --study outputs/autonomous_s7_20261014 --export
```

Pure/mock checks of this bundle:

```sh
.venv/bin/python -m pytest -q results/s7_continuation_20261014/offline_analysis_preparation/test_analyze.py --basetemp outputs/audit_l_20261014/public_analysis_tests
```

The executable analyzer is also copied into the completed archive by the export. This preparation bundle does not release or start the study and has its own provenance manifest.
