# Delayed-matching continuation from the retained population

The new question is whether an inherited pursuit population can evolve choices that depend on an earlier
shape cue, while preserving useful performance on earlier tasks. The completed T85 information measurement
shows that retaining the cue pays; the prior six-genome baseline shows pursuit with a strong broad-target bias.
The measuring instrument is never installed in the organism. Cells keep their local asynchronous rules.

One ordinary 24-generation search imports all 32 ordered survivors from AO's balanced24 population. This
population is chosen for its prior retention evidence, not as the best genome on the small matching baseline.
Scores and RNG state start fresh; this is a continuation of genetic material, not an exact AO resume. Native
seed 53233 and confirmation block 146 are audited before reservation. The source and exact float32 row bytes
are pinned. The native 32 parents/224 children, sexual reproduction, two scaled point additions, top64 recheck,
random tie handling, and physical prices remain unchanged. No duplication, deletion, immigration or bonus for
a prescribed behavior is added.

Each eight-life selection draw has fixed order matching85, POOL, matching85, persistent, repeated twice.
The eight additional recheck lives use the same allocation. Fitness is the native mean of per-life net F,
including the existing extinction surcharge: 50% matching85, 25% POOL and 25% persistent. Every candidate in
a generation sees the same seeds and fixed contexts. Worlds never respond to the population. This allocation
is a deliberate attempt to preserve earlier capability, not a proven optimum or hard retention guarantee.

Generation 24 rank 0 is the primary endpoint. Generation 8 rank 0 is a passive, predetermined observation; it
cannot replace the final endpoint after outcomes are seen. Every generation receives a deterministic native
checkpoint. Native validation occurs at generations 0, 4, 8, 12, 16, 20, 23 (zero-based), using the matching85 base;
validation does not select the endpoint. All diagnostics and their call counts are retained. No stopping,
reselection, longer run, sample top-up or reward change is triggered by interim scientific results.

After the search completes, four fixed genomes are frozen before confirmation: AM_reference, AO_start,
mixed8 and mixed24. Each receives 512 fresh, shared seeds in each of seven worlds:

| World | Use | Definition |
|---|---|---|
| match85 | Main new capability | Exact admitted delayed-matching preset, T85 |
| pool | Earlier capability | Unchanged ancestral fast-conduction POOL, T1024 |
| persistent | Earlier capability | Unchanged moving persistent target, T1024 |
| blink80_20 | Earlier capability | AO's longer irregular cue gaps, T1024 |
| match1024 | Development-known diagnostic | Exact matching preset, repeated T1024 |
| short_blank | Diagnostic | Matching85 with blank interval uniform 2–4 |
| transfer | Reserved parameter combination | Matching85 with blank uniform 10–30 and radius uniform 3–5 |

The same fixed endpoint is evaluated everywhere. Transfer and short-blank outcomes never enter selection or
choose another endpoint. This is limited parameter transfer, not broad unseen-task generalization. A shorter
blank changes opportunity timing and throughput; a cross-world fitness difference is not a memory effect.
T85 admission does not automatically admit T1024 or the other diagnostic worlds into future selection.

Report matching outcomes by sample class: correct, wrong, unfinished and timed-out opportunities, completion
coverage, correctness among completed choices, and correct choices per opportunity. Report the change in
narrow-choice probability between narrow and broad cues, both per opportunity and among completed choices.
Fitness alone cannot establish matching: broad-target pursuit can earn positive reward without cue dependence.
Use native ABI5 correctness counters; the older `captures` telemetry records a physical slot and is not a
correctness readout. Conditional choices would be behavioral evidence, without isolating a neural memory
mechanism from other persistent organism state.

Primary comparisons are mixed24 minus AO_start in match85, with mixed8 and mixed24-minus-mixed8 as fixed
trajectory observations. Report all class outcomes and physical cost contributions alongside F, including
whether gains merely reduce costs or abandon one cue class. Retention is measured directly in the new genome
on POOL, persistent and blink80_20 against both AO_start and AM_reference. The 90% margin is diagnostic and
allows some loss; it is not a gate before richer exploration. Ratios and paired uncertainties use whole lives
as clusters, including repeated-task trials within each life. One search is not evolutionary replication.

The search requires 61,558 research calls: 61,440 selection calls, 112 validation calls and six native final/
growth diagnostic calls. Because the ABI requires integer durations, the two native growth diagnostics
requesting half of 85 are mapped by the study adapter to T42 (floor of 42.5), not an exact half life. Only this
nonselection diagnostic duration changes; all selection and main confirmation stay T85. Four startup calls replay an existing full/fast golden pair and an existing ABI5
full/fast matching case. Confirmation adds 14,336 research calls plus the same four startup calls. The complete
maximum is **75,902 calls**. There is one attempt, no automatic retry or budget extension.

The package cap is **10,800 CPU /7,200 wall seconds**. A conservative 120 CPU/120 wall allowance covers prior
namespace audit and preparation, leaving **10,680 CPU /7,080 wall seconds** for monitored execution. Search
may consume at most 8,280 CPU seconds; 2,400 are reserved for confirmation and cleanup. One worker uses two
kernel threads, at most 8 GiB address space, with a 4 GiB combined owned RSS stop and 4 GiB host available-memory
floor. The watchdog owns, meters and clears its workers, including descendants. If a cap or guard ends the
study early, preserve evidence and report incompletion; do not interpret an incomplete confirmation as a null.

Raw native confirmation rows are saved before validation, then separately reconciled to physical costs,
class conservation and native selection scoring. Startup pins numerical identity and existing truth. The
full ordered population, checkpoints and recorded genetic operations allow terminal replay without new
simulations or random draws. Native search retains aggregate health, not every per-life ledger; this limit
is explicit. Public registration and actual-input review precede execution. The user's autonomy instruction
covers this bounded local study; no spending or new organism communication is involved.
