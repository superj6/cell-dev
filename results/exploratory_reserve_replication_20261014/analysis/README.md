Run the frozen reader from any working directory with absolute paths:

```sh
PYTHONDONTWRITEBYTECODE=1 /path/to/python /path/to/study/analysis/analyze.py --study /path/to/study --out /path/to/new/audit-output
```

It produces output only for a complete, released, resource-settled study. Before
release it reports incomplete with no outcomes. Source dependencies resolve from
the archive's `production/` and `original/` bundles. For source/input-only checks,
import `analyze.py`, call `verify_protocol(study)`, then call
`native_audit.initialization_audit(study, protocol, reader.external)`; compare the
returned object with `initialization_replay.json`. Those operations replay recorded
additions without drawing mutations or running numerical goldens. The retained
`verify_preparation.py` records the original one-time audit and writes audit
receipts exclusively; use the read-only entrypoints to inspect a frozen archive.
