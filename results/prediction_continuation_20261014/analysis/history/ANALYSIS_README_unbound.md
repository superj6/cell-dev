# AF independent reader

This is an unbound source draft. It cannot emit scientific outcomes until a
reviewed protocol hash is installed after registration and once-only preparation.
No input genomes, initial populations, research seeds or runtime results have
been copied or generated by this reader preparation.

The reader keeps the exact AE whole-life ABI3 accountant (57 raw columns and
60 named production columns). Natural extinction and paid guard endings remain
in fitness. The initial cell is not a birth. The two primary paired contrasts
are AF_D90 minus AE_D90 and AF_L92 minus AE_L92, each on the same 512 seeds.
Each contrast retains 73 vectors: all 60 named columns and 13 additive accounting
terms, for 146 vectors total. This is ordinary continuation evidence; captures
and cost savings do not identify prediction, memory or a distributed mechanism.

Native auditing narrowly reuses Z's recorded-operation and shortlist helpers.
It binds the two generation-4 final population rank-zero endpoints, all final
population rows, checkpoint/log hashes, exact configuration and both initial
populations. Initial operations will be replayed only after authorized preparation;
full native replay requires terminal search output. No random draws, life runs,
compilation or numerical goldens are performed by the reader. Native selection
logs do not retain every per-life ledger, so full raw accounting applies to the
four fresh confirmation rows, not all search diagnostics.

The source-only checks use one four-row numerical fixture, the actual producer's
pure reporting/cost functions extracted from its AST, and archived process
receipt metadata. They check ABI3 width, role/seed order, production fitness,
aggregate identity, cost projections, counts and four-field ownership. The final
25 checks pass; five affected checks were repeated after test-only portable path
handling changed. Earlier test-scaffolding failures are retained in audit logs:
a deferred-annotation stub was missing, and a test compared reassociated floating
point arithmetic exactly. Neither failure required a scientific reader change.

When bound, the CLI is `python analysis/analyze.py --study <study> --out <new-dir>`.
It verifies all required evidence before writing any summary or paired vectors.
Incomplete evidence produces an incomplete status without outcomes. Execute in
a fresh process with PYTHONDONTWRITEBYTECODE=1; the native audit resolves only
pinned genome/spec definitions and refuses loaded engine/execution modules.
