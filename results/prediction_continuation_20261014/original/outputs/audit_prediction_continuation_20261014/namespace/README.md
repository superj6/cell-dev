# AF candidate namespace audit

This is a read-only candidate audit, not registration or permission to run. It proposes native genetic/run seeds 53224 (D90) and 53225 (L92), plus confirmation IDs 52,310,000–52,310,511. The whole half-open decimal block [52,310,000, 52,320,000) is checked.

A native genetic RNG seed is not a simulation life ID. Each run hashes its seed with the existing LIFE purpose stream, generation/final index and within-draw index. Each run has 28 generation IDs, 32 periodic validation IDs and 4 final IDs: 64 distinct IDs. The initial three generation IDs are shared by 256 candidate genomes; four separate recheck IDs are shared by the top64. Two final diagnostic calls per run shorten final-index0 to T512 and intentionally reuse its two IDs. The four confirmation roles share512 fresh IDs. Three production numerical-identity calls each repeat the standard seed11/T200 full/fast golden pair; those six calls are counted and deliberately are not fresh research IDs.

`namespace_audit.py` uses only extracted pure hashing definitions and the declarative seed schedule; it never imports the engine, draws genetics, copies candidate genotypes, compiles or simulates. It rereads one representative of every known distinct seed payload for these NEW candidates and reads all seed-token members of added/changed NPZs. Previous no-match conclusions are not transferred to different candidates. Unchanged-file reuse is based on the recorded filesystem identity/stat tuple and exact seed-payload SHA256; this does not claim every full unchanged NPZ was rehashed.

`candidate_namespace_review.json` classifies literal/numeric history matches, checks all546 AE IDs and all515 AD IDs, and checks138 AE canonical/public raw-row seed lists and full-file hashes. Six synthetic fixture files changed during the initial scan; their seed payloads were reread after the independent reader froze. The remaining malformed NPZ is an explicit synthetic file-hash placeholder, with exact bytes and hash recorded. No scientific genotype or outcome arrays are loaded.

`final_namespace_delta.py` repeats the same-candidate added/changed seed-member and reservation check after reader freeze, records root-owned illustrative AE seed reuse if present, and emits `seed_audit.json`. The historical prediction use of “block131” has a43,000,000 base, yielding44,310,000; it does not reserve the proposed51,000,000-based block. AE's previous52,310,000 endpoint is exclusive.

`history_references.json` contains exact repository paths, containing commits, byte lengths and SHA256s for13 already committed historical proof artifacts. They are deliberately not copied again. Full historical namespace verification therefore needs those repository artifacts; this audit directory alone is not the complete historical proof. No network fetch or unpinned live-source substitution is permitted. Current scientific inputs and production definitions will still have to be packaged if root later registers the study.
