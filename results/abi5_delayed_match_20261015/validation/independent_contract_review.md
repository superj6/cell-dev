# ABI5 contract review — 2026-10-15

Source review covered `spec.py`, `reference.py`, `kernel.c`, `build.py`, `evaluate.py`, `readouts.py`, and the maintained `lifesim.js`. This is an engineering and scientific-interpretation audit, not evidence of evolved matching. No AO outcomes were accessed.

The review found one enforcement gap and it is now fixed: Python already rejected inconsistent class-specific opportunity counts, while C and JS checked only monetary reconciliation. C `task_close` and JS `close` now set `ledger_mismatch` when either class fails `opened + carry = correct + wrong + timeout + unfinished`. Injected narrow-open/broad-timeout counters demonstrate that globally balanced counts cannot conceal a class-specific failure. Normal tested lives retain identical outputs.

- **Class leakage:** `task_enter`/`taskEnter` use separate streams 27–30 for class, durations, geometry and side, keyed by trial and purpose. Geometry contains no class branch; physical slot 0 remains narrow and slot 1 broad. Choice placement is class-independent conditional on current body state. The body's position, velocity, morphology and local state may retain the sample legitimately. Matching alone cannot locate that memory in a neural circuit. Viewer/hash labels are external observations, never GRN inputs.
- **Sensory availability:** sample width changes only the existing scalar spatial receptor rate. A stationary sensor exactly at the sample center has equal rate in both classes; off-center sensors or movement are necessary to distinguish them. The candidate bound stays `lam_bg + lam_s*(1+b2_amp)` in every phase. Blank/gap remove both signal components. `blank_min > d_min` prevents direct sample receptor deliveries from extending into the choice; cellular traces, delayed intercellular messages and chemistry intentionally persist.
- **Clicks and boundaries:** a successful first hit latches consumption and cancels the old timeout before record 11; later same-group clicks miss. Scene removal waits until group end, so same-time receptors retain the old scene. `world_to(t)` is strictly-before: an exact-deadline click can resolve the old choice; an event exactly at actual life end is excluded. Positive reset duration prevents same-group trial recycling. Extinction leaves world scheduling running through T; guards stop at their actual endpoint.
- **Accounting and scoring:** a choice opening exactly at `t_open` is an opportunity, while a pre-window choice contributes carry-in only on a counted resolution or unfinished endpoint after window opening. Pre-window actions still affect the scene. All ports charge correctness independently of physical slot; Python repricing uses the conditional counts. `captures` and `b2_clicks` remain physical hits, including in generic run summaries. Subsequent studies must retain the full ledger and `matching_summary`, rather than interpret `captures` as success.
- **Substrate and compatibility:** ABI5 appends world/readout fields; the 875-value BODY genome, 25 regulatory inputs, local messages and asynchronous cell updates are unchanged. External phase scheduling adds no shared cell tick, reward input or global communication channel. Python's default remains ABI2; explicit older callers pad neutral fields and project their previous shapes/hashes. JS retains its existing ABI3 default and restricted browser-supported world subset; validated exported worlds, not arbitrary viewer overrides, define parity scope. Full-width trial folding is retained in JS.

Positive reward remains a cheap-reflex alternative: a sample-blind resolved choice pays an expected 225 before costs. Width-dependent selectivity, timeouts, incomplete choices, action frequency and morphology can change F without improving conditional matching. Report both sample classes, completed-choice accuracy, coverage, timeouts/unfinished opportunities and the full physical bill. Retention or prediction claims need separate evidence.

The smallest confirmation panel consistent with plan 0.4 is four frozen **measurement** roles on 512 fresh paired T1024 lives (2,048 confirmation lives): retained-sample instrument M; the identical instrument with only its stored sample statistic erased A; the strongest reflex R chosen on disjoint tuning; and the strongest do-less D chosen on that tuning. Declare the finite reflex family (narrow preference, broad preference, nearest current choice) and both quieter/smaller variants before tuning. “Best” means best within that declared family; a broader best-measured claim requires retaining the additional candidates in confirmation.

Use off-center sensor sites at R's footprint, ordinary receptor pings and production-constrained strokes/clicks. Instruments may aggregate observations for measurement but cannot read true class, phase, trial, seed, target coordinates or future timing. M/A share preprocessing, phase inference and pre-choice actions; only the retained class statistic differs. Reflex history must be shorter than `blank_min - d_min`, avoiding residual sample deliveries in its observation window. Charge sensing, footprint, action and any virtual relay consistently; computation being free is an explicit instrument limitation, not an organism feature.

Require paired M−R and M−A gains each ≥1 F and >3 SE, with D−R below one-quarter of M−R; retain all outcomes. A 128-life sensor/classifier pilot can diagnose information availability but cannot satisfy admission or substitute classification accuracy for an F comparison. Freeze tuning calls, scoring seeds, backend totals and resource limits before execution. No instrument or winning tissue body becomes part of evolution.
