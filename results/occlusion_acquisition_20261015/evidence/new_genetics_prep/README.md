# AN recorded native audit — preparation only

This package adapts the completed AM audit to the single eight-generation AN acquisition run. It reconstructs all 32 imported genomes and 1,792 recorded offspring, checks the final ordered 32-row population and origins, and independently reconstructs the prescribed generation-four 32-row checkpoint from the first four generations. The midpoint must retain the exact completed-run log prefix, extended identity, checkpoint bytes and rank-zero endpoint. No evolution, numerical-identity calls, engine builds or lives are executed by this audit.

`selection_replay.py` is an exact AM copy. Its ordinary 8+8 selection checks are generation-count independent. The genetic primitives are the frozen study's unchanged `replay_ops.py`; the prepared receipt pins both study replay helpers. Replaying a prefix repeats recorded additions only and does not draw random numbers.

The initial top-64 ranking cannot be fully independently verified because unsuccessful parent base scores and exact tie permutations were not retained. The audit checks the logged ordered shortlist and the pooled top-32 survivors with the inherited numerical tolerance. Guarded search lives retain their penalties; aggregate guard counts are reported. Ancestry and active genes do not demonstrate functional circuitry or memory.

After explicit root terminal authorization, from the repository root:

```sh
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python outputs/audit_occlusion_acquisition_20261015/new_genetics_prep/execute_full_audit.py --run
```

Without `--run` the wrapper is inert. Execution requires a complete terminal budget and exact prepared protocol/helper hashes; it refuses an existing terminal output directory. It preserves the exact helper sources, command, first stdout/stderr and execution receipt under `outputs/autonomous_occlusion_acquisition_20261015/terminal_review/native`. No actual replay has been performed during preparation.

Validation: 21 synthetic checks passed, including complete eight-generation replay, six midpoint cases, recorded-operation corruption, duplicates, origin counters and the 8+8 schedule. The tests construct data in memory and one small temporary prefix fixture; no real AN runtime data was read. Executable helper Ruff checks pass; the inherited compact test style was not reformatted. Two additional fail-closed metadata guards (fixed protocol/search-completion scope) were added after this suite; replay functions did not change.
