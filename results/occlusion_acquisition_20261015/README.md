# AN: acquiring longer-gap performance while retaining earlier tasks

This bounded local study continues all 32 ordered survivors of AM's original-price arm. It asks whether
ordinary evolution can improve capture performance when target cues disappear for longer, while preserving
POOL and persistent-target performance. The decision follows AM's complete result; it is not a queued
price sweep or a requirement to establish mechanism before exploring a useful new information demand.

One uninterrupted eight-generation search uses the existing 32+224 native population, eight initial lives
and eight extra lives for the top 64. Every group of eight selection lives contains two POOL, two persistent
and four blink80/20 contexts, in the fixed order POOL, persistent, blink, blink, repeated. All prices remain
original (capture value 500). The blink world changes mean dark duration from 5 to 20 at mean visible duration
80, with the same persistent-target physics. Existing ABI4 supports this; no new cell rule or signal is added.

Generation-four and generation-eight rank-zero genomes are fixed before fresh confirmation. The midpoint
is copied after the native checkpoint write without a random draw or evaluation. Final is never replaced by
a better-looking midpoint. The AM start and both checkpoints each receive the same 512 fresh seeds in five
contexts: POOL, persistent, brief blink80/5, longer blink80/20, and faster-turning blink80/20 (turn mean 100).
The last is an untrained diagnostic combination: the retained metadata audit found no prior exact setting,
but its factors and nearby tasks were already explored. This supports at most narrow transfer evidence.

The primary is generation-eight minus start captures in blink80/20. Both checkpoints are also tested for
90% capture retention in each old task. Report every role/world, capture and cost changes, click fractions,
body counts, dark/bright captures, and paired environmental interactions. A 10% tolerance allows some loss.
Captures during darkness alone do not identify memory; coasting, waiting, changed bodies and reactions to
current cues remain alternatives. One continuation does not establish curriculum or search-depth superiority.

Scope: 20,534 search research lives plus 7,680 confirmation lives and eight existing-truth startup calls:
28,222 total. Candidate native seed 53,231 has 180 distinct life IDs. Confirmation uses 52,410,000–52,410,511
inside reserved block 141 once protocol preparation is accepted. Full/half native final diagnostics deliberately
reuse two seed IDs. Initial population import resets IDs, RNG and fitness; it is not a resumed checkpoint.

Hard limits: 10,800 CPU seconds total, 7,200 search and 3,600 confirmation, 5,400 wall seconds; one two-thread
worker, 4 GiB aggregate owned RSS, 8 GiB worker address space, and at least 4 GiB available host memory.
No automatic retry, smaller rescue matrix, extension, outcome-based endpoint substitution or paid compute.
Prospective source/input reviews and publication precede runtime release. Outputs belong in this directory.
After the complete result, reconsider the next highest-value experiment across richer tasks, search strategy,
retention/cost tradeoffs and causal analysis, following the user's explicit guidance against narrowing onto
one line of tuning.
