This independent analyzer reads a complete fixed visibility-information study using only Python's standard library and NumPy. It never imports the simulator, builds a library, executes controller code, or runs a life. The study's 26 rows must all finish on the registered 512 paired seeds, and all 82 validation lives plus the first-attempt monitor receipts must reconcile before any scientific outcomes are emitted.

Run `python analysis/analyze.py --study /path/to/archive --out /path/to/fresh/output` from a portable archive, or use the same entry point in this audit directory against the working study. Omit `--out` for a read-only check. An incomplete study produces only an incomplete status and its cause. Output directories must be new. The final protocol SHA is anchored inside the analyzer; a different registration needs independent review.

The three implementation files are `analyze.py`, `accounting.py`, and `candidates.py`. The two synthetic suites are `test_analyze.py` and `test_accounting.py`. Run them with pytest using a temporary directory under `outputs/`. Test fixtures explicitly synthesize ledgers, libraries, and process receipts; their tests never execute the synthetic library files. The full candidate reconstruction test reads the retained source literals and exact parameter records, then independently reconstructs the geometry and program arrays without importing those sources.

The archive must preserve the working study's relative protocol, `original/` (frozen ABI3 package), `inputs/`, validation and row paths. Copy production pins into `production/<repo-relative path>`; production source must never resolve to the intentionally different ABI3 package in `original/src/`. Dependency budget receipts may be stored in `original/<repo-relative path>`. Archived copies take priority over mutable repository outputs. Operational receipts can be at archive root or `operations/`. The finalized validation archive includes all four library files, generated C sources, the report, and every raw validation NPZ. Final research rows include both world completion markers and every row/checkpoint pair.

The raw contract remains ABI3 scratch visibility with 57 columns. Scratch columns 21 and 22 are dark and late captures, not production beats or P_int. Derived low-light captures map column 21 to the production ABI4 readout through the accepted bridge. The analyzer reconstructs ordinary physical costs, income, net and F without an extinction penalty. Any unexpected extinction of these fixed static candidates invalidates the complete study. Every raw column is checked for finiteness and included in summaries; count, census, capture, cell-time and morphogen conservation checks accompany the accountant identities.

Both reference choices are fixed whole-sample candidates. The analyzer selects the larger whole mean of R0/R1, reports I−R0 and I−R1 separately, and retains all eight do-less contrasts. Each do-less margin is 0.25(I−R)−(D−R), calculated per paired life. Ratios use paired means and covariance-aware delta-method errors; negative effects and fractions outside zero to one are retained. A weak or nonpositive denominator is explicitly marked. Selection makes these standard errors descriptive rather than selection-adjusted confidence bounds.

The full information yardstick is a retained external controller with central computation. It is not an evolved organism, an attainable performance ceiling, or a proposed organism behavior. A removes a broad visibility model; B suppresses actions while believed dark. Neither isolates memory. Strong differences can reflect sensing, state estimation, model assumptions, action policy, or costs. This measurement can establish useful information payoff and assess doing less; capability-specific admission, evolved behavior, and the held duration extension remain separate and incomplete.
