# Resource selection comparison — prospective registration

The preceding continuation improved economy while losing acquisition on some environments. This study tests
whether preserving candidates with useful acquisition tradeoffs helps a lineage accumulate abilities.
Ordinary mean-fitness selection is compared with selection on three task-specific capture means and ordinary
fitness. Both inherit the full final population and use the same fixed worlds, prices and mutation rules.

Each branch runs four generations. The same predeclared rule then picks one genome from each final population
using its existing selection results. Those unchanged genomes and two ancestors face 512 fresh shared lives
in five worlds, including a new reserved resource combination. A collection of specialists is not counted as
generalization. Food, retained acquisition, physical costs and fitness are reported together.

The complete maximum is **30,808 calls**, under **5,400 CPU /3,600 wall seconds**, including preparation and
terminal allowance. One two-thread worker runs at a time, with a 4 GiB RSS stop, 8 GiB address-space limit and
4 GiB host-memory reserve. No paid compute. Source and supplied-data checks precede exact-input review,
prospective publication and explicit runtime release. This archive records no scientific execution.

See [PROTOCOL.md](PROTOCOL.md), [protocol.json](protocol.json), the
[selector source note](PARETO_SOURCE_NOTE.md), and [actual-input review](reviews/actual_input_review.json).
All source/input and namespace evidence is preserved. Verify without simulation:

```sh
.venv/bin/python results/resource_patch_selection_20261015/verify.py
```

This is one matched exploratory comparison. It does not establish formal information-payoff admission,
memory, broad generality or superiority to handwritten algorithms.
