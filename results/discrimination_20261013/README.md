# Discrimination measurement: prepared, not launched

This archive fixes a measurement of whether the existing controller's decoy model pays at the reflex's
56-cell footprint. It contains **no new scientific result**. The controller remains an external measurement
tool; organism rules, the ABI and the audited harness sources are unchanged.

- Seven fixed candidates on 512 shared fresh T1024 lives: **3,584 candidate-lives**.
- Block 30, seeds 51,300,000–51,300,511; two workers; **1,800 cumulative CPU-seconds**.
- Existing SPECK conduction d0=1, d_min=0.5 and the registered harmful-decoy settings.
- Primary comparisons: full controller against the better whole frozen/retuned reflex and its matched ablation.
  Both fixed-reflex contrasts are also reported. Selecting the reference on these outcomes makes its paired SE
  descriptive and conditional, without selection adjustment.
- Any guarded, invalid, corrupt or unexplained incomplete life leaves the study incomplete. No individual life
  is selectively removed or replaced; valid negative scores remain.

The full protocol is [prereg.txt](prereg.txt). [protocol.json](protocol.json) contains exact candidates, seeds,
world settings, numerical identities and source hashes. [provenance.json](provenance.json) binds every archived
artifact to its bytes and maps original repository paths to their copies under `original/`.

`preparation/` preserves the standalone worker, cumulative CPU monitor and pure/mocked tests. These are archival
copies; run the working versions under `outputs/autonomous_discrimination_20261013/` after root registers the
protocol and creates the release pins. No release file or compiled library is included here.

The original full and ablated controller sources and parameters are unchanged. Setting model 1 to model 0 removes
decoy belief, attribution of pings, steering avoidance and tap veto while retaining ordinary target tracking.
It measures that broad mechanism, not one classifier, an evolved circuit or a matched-footprint tissue algorithm.
Controller parameters were transferred from ring5, only three do-less candidates are tested, and controller
computation is free. A passing measurement never automatically puts the world into selection.

The archive includes existing T64 validation callback logs. Their twelve replay comparisons are checked offline;
they provide bounded leakage/parity evidence, not universal long-duration validation. No new lives ran during
preparation. The fast measurement's event hashes will be zero; checkpoint SHA256 receipts protect saved bytes.

From the repository root, verify the archived hashes, protocol and saved replay actions without simulation:

```bash
.venv/bin/python results/discrimination_20261013/validate.py
```

After launch, preserve every full ledger and controller diagnostic under the working study. Atomic candidate
checkpoints and cumulative CPU records allow verified reuse of completed candidates within the original cap.
Failed validation evidence stays uncommitted and cannot automatically be replaced. An unfinalized resource
record requires reconciliation before resuming. Results will be archived and reported separately.
