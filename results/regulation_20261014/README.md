# O: local regulatory inputs with cell composition held constant

This fixed follow-up separates ongoing gene regulation from division and death,
using three existing interventions on the row38 founder and both ordinary D endpoints.
It asks whether specified local inputs to the gene network contribute to the descendants' gains.

The three conditions keep cell composition constant after t768: division/death blocked,
the same with GRN inputs 18–22 masked, and broad freeze. Measure t800..1536 in fast POOL
on 512 shared fresh seeds. Both endpoints and all nine arms are retained.
[PREREG.md](PREREG.md) fixes the contrasts, limitations and failure rules.

The scope is 4,608 research lives and a 3,600 CPU-second cap, including startup validation
and monitoring. Two workers wait until both M and N complete. Preparation itself runs no lives
and creates no release marker. All original sources and numerical settings stay pinned.

The mask includes static contact information as well as activity traces. Its effect cannot
alone establish adaptation, memory or use of changing evidence. Broad freeze also stops
phenotype and effective-weight updates. These genotypes retain different shapes and states.

The independent analyzer reads completed ledgers only, reconstructs accounting and all
16 paired contrasts, and preserves every raw result. Its pure tests use synthetic data.
The preparation archive includes the motivating H record, fixed D endpoint receipts,
source snapshots, namespace audit, tests and a non-releasing readiness template.
