This is a read-only candidate audit. It does not register or reserve IDs, create scientific inputs, draw genotypes, compile kernels, or run lives.

All three whole half-open blocks are checked, covering [52,320,000, 52,350,000). The 546 selected IDs are distinct. There are no new native genetic/run seeds. The existing standard ABI3 seed 11 full/fast identity pair is explicit reuse; within each new stage, sharing its seeds across the fixed genotype roles is intentional.

The initial inventory covers 75,086 NPZ paths. It reopens one representative of every distinct unchanged SHA-pinned seed payload against these new ranges, and reads seed-token members from all added or changed files. Earlier no-match conclusions are not assumed to apply to new ranges. Unchanged file reuse uses the recorded filesystem stat identity and pinned seed-payload equivalence, not a claim of full-file cryptographic rehashing.

No actual overlap was found. Twelve integer JSON matches name AF block 131's excluded upper endpoint, 52,320,000. Source matches are that endpoint, unrelated fractional/hash substrings, and the explicitly classified unexecuted root candidate-registration draft. Eight known producer tamper-test placeholders are JSON files with NPZ suffixes and contain no seeds or genotype arrays; their exact bytes and producing test source are recorded. They are not unexamined research records.

Completed AF coverage explicitly binds all 128 registered native life IDs, its 512 confirmation IDs, four canonical/public raw row pairs, and the recorded generation seed arrays from both native lineage logs. The complete registered schedule also covers periodic validation and tiny final diagnostics. Earlier AE and AD registrations are separately checked. The final delta runs after the source/reader fixture freeze and AF terminal publication, scanning only changed or added seed members and current matching JSON/source declarations. It includes the corrected root registration draft without executing it.

`seed_audit.json` records exact lists and the final proof hashes. `history_references.json` identifies 17 already committed historical proof artifacts by repository path, public commit and SHA256. Their 36,660,377 bytes are not copied again. Full historical namespace verification therefore requires those repository artifacts; this folder alone is not the complete historical proof. No network fetch or silent live-source substitution is used. Scientific experiment inputs, if separately authorized later, remain subject to their own complete archive requirements.

Only seed members and seed-bearing identity metadata are inspected by these audit scripts. Root registration, input preparation, readiness and execution remain separate actions.
