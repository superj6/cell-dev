# AO terminal native audit preparation

This package is source-only until root authorizes execution after the AO monitor has finished and its owned processes are cleared. It never evaluates an organism, builds an engine, invokes numerical identity, or redraws genetic randomness.

The execution helper is inert by default. Its explicit `--run` path requires both search completion markers and a complete terminal budget, verifies every prepared helper and producer-helper hash, and creates `terminal_review/native` exclusively. The command, exact helper bytes, stdout, stderr, exit status and CPU/wall use are retained. Root terminal authorization remains a separate prerequisite.

For each of `unchanged` and `balanced`, the audit reconstructs the initial32 ordered genomes and all5,376 recorded offspring across24 generations (10,752 point mutations per arm), including all32 final raw rows and gene origins. It separately replays the generation8 prefix and all32 midpoint rows, checks the passive snapshot and exact final-log prefixes, and confirms that rank0 matches each prescribed endpoint. The paired first256 candidate bytes and operation signatures must agree between arms.

The ordinary eight-plus-eight selection helper is byte-identical to the completed AN/AM helper. It checks the recorded64-member shortlist ordering, pooled scores and selected top32. Unrecorded base fitness of parents outside the shortlist and the exact random tie permutations cannot be reconstructed. Complete per-life search ledgers are not retained; the audit reports aggregate guards without discarding their penalties. Ancestry and active-gene counts do not establish functional circuitry or memory.

`test_replay.py` uses only synthetic arrays and recorded arithmetic, plus one shared synthetic midpoint prefix. Its21 checks cover full24-generation reconstruction, the midpoint8 prefix, corruption rejection, eight-plus-eight pooling and exact reviewed operator reuse. `test_tmp` is disposable synthetic test output and is excluded from the curated preparation manifest.

No AO outcomes or actual runtime checkpoints are opened during preparation. The protocol hash and frozen producer helper hashes are static preparation metadata. `adaptation.diff` and `helper_origins.json` retain the narrow source changes and exact AN origins.
