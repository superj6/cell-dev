**Why this over the alternatives.** More generations on the same two tasks can improve capture rates, but do not add a new information demand; the control already answers that alternative. A mechanism probe now can identify dependence of the existing behavior, but does not itself advance the generated algorithms. A crossover/clonal comparison targets a plausible preservation issue without evidence that it currently limits this lineage. Neither should displace this capability-oriented experiment.

Long darkness is not guaranteed to demand neural memory: continued movement, slow receptor/GRN state, waiting until light returns and indiscriminate clicking can all help. Even a dark-capture gain would not establish prediction or a new circuit. A later causal probe would be needed for that claim. Nor is failure a world-admission failure: no hand-built body test is proposed. This experiment asks the narrower, useful question of whether the existing evolution system can acquire performance under stronger loss of current sensory information while retaining prior abilities.
