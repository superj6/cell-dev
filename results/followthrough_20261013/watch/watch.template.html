One life is an illustration

A seed can favor either body. The default seed was fixed before viewing; changing it does not change either genome. Each life ends at t 1024. F is net income per unit time, with the production extinction charge included at the end.

The measured effect comes from many lives

Both worlds use the same faster conduction settings. The chase view follows each body at the same scale; targets can diverge after captures because each life evolves independently. Playback speed changes display timing.
Reproducibility and simulator license

The unmodified cell-dev lifesim.js engine and both archived genomes are embedded in this file. Engine source: public repository. The engine includes GNU C Library math code and is distributed under the LGPL 2.1 or later. This viewer introduces no new organism rules.
